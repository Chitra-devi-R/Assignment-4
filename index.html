Welcome to ShopEase

ShopEase is a demo storefront built to showcase two core HTML5 capabilities: native drag-and-drop interaction and the two flavours of Web Storage — localStorage and sessionStorage. Drag a product into the cart below, then save your details so ShopEase remembers you on your next visit.

About This Page

This page was built as an academic assignment demonstrating HTML5 Drag and Drop APIs and Web Storage (Local & Session Storage), using only semantic HTML5, CSS3 and vanilla JavaScript — no frameworks or libraries.

Quick Facts

  • Pure HTML5 / CSS3 / JS
  • No external libraries
  • Works fully offline

Help
